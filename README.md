# 🕴️ Soft Butler

> **"We build trust in applications — through people and quality thinking."**

Soft Butler is a premium Quality Assurance (QA) and Software Testing service provider. Originally started as a QA education initiative, we have evolved into a professional community that sets a "new normal" in software quality, focusing on real-world impact over rigid rituals.

---

## 🚀 Key Features

- **Professional QA Services**: Comprehensive solutions ranging from QA Audits to Release Acceleration.
- **Modern Tech Stack**: Built with Next.js 15, Tailwind CSS, and Framer Motion for a fluid, premium user experience.
- **Responsive Design**: Optimized for all devices, from desktop to mobile.
- **Interactive UI**: Featuring smooth animations, industry-standard icons (Lucide React), and a clean, professional aesthetic.
- **Dynamic Routing**: Multi-page architecture with SEO-friendly URL structures and redirects.

---

## 🛠️ Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (Page Router)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Notifications**: [React Toastify](https://fkhadra.github.io/react-toastify/introduction/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)
- **Deployment**: [Netlify](https://www.netlify.com/)

---

## 📂 Project Structure

- `pages/`: Next.js page entry points.
- `src/pages/`: Main page components and logic.
- `src/components/`: Reusable UI components (Navbar, Footer, Hero, etc.).
- `src/App.tsx`: Main layout wrapper.
- `public/`: Static assets (images, logos).
- `netlify.toml`: Netlify deployment configuration.

## 💻 Getting Started

### Prerequisites

- **Node.js**: Version 18 or higher.
- **npm**: Version 9 or higher.

### Installation

1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd softButler-multipage
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

### Local Development

Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

### Building for Production

```bash
npm run build
npm run start
```

---

## 🌐 Deployment

This project is configured for deployment on **Netlify**.

1. Connect your repository to Netlify.
2. The `@netlify/plugin-nextjs` will automatically handle the build and deployment.
3. Build command: `npm run build`
4. Publish directory: `.next`
